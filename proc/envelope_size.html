envelope_size

private pure function envelope_size(me)

Number of elements in the envelope of the Cholesky factor (i.e., the storage required for L, in reals). Returns 0 if not analyzed.

    pure integer(int64) function envelope_size(me)

    class(cholesky_minnorm_solver),intent(in) :: me

    if (me%analyzed) then
        envelope_size = me%ptr(me%m+1) - 1
    else
        envelope_size = 0
    end if

    end function envelope_size
